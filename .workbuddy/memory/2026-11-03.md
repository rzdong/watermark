## 网站完善（website/index.html）

把原来 40 行的占位页升级成完整产品页，单文件 + `website/assets/` 图片素材。

**结构**：导航 → Hero（深色渐变 + 主界面截图）→ 数据条 → 功能九宫格 → 效果（PDF 前后对比、图片拖动对比、图片水印两栏）→ 支持格式表 → 参数手册（内容/布局/PDF 三组表）→ 原理（增量更新说明 + PDF 结构代码块）→ 四步流程 → FAQ（details）→ 下载 → 页脚。

**素材全部真实产出，非伪造**：
- 示例 PDF 与前后对比图：`swiftc` 编 WatermarkCore + 临时 main，用 CoreText 画一份虚构「技术服务合同」（2 页 A4），走 `WatermarkProcessor` 真实加水印，再用 PDFKit `thumbnail` 渲染成 PNG。
- 两张风景图同样是 CoreGraphics 现画的矢量插画，再经 ImagePipeline 加文字/图片水印。
- 主界面截图：写离屏渲染工具 `/tmp/wmsite/shot`，`NSHostingView(ContentView)` + `bitmapImageRepForCachingDisplay` 出图。**关键坑**：AppModel 里的 `Task.detached` 在 `RunLoop.main.run(until:)` 阻塞期间拿不到主线程执行机会，`model.preview` 始终 nil —— 改为先同步调 `PreviewRenderer.preview` 再直接赋值。
- 设置面板截图最后没用：SwiftUI `Slider(value:in:step:)` 在 macOS 会画刻度线，官网观感糙，删掉该节。

**踩坑**：用 python 按字符串 index 做块替换时，匹配前缀 `图片水印` 命中了两处（滑块块标题「图片水印 · 左右拖动对比」），把整个滑块块误删。教训：块替换的锚点要用足够长的唯一子串，或替换前 assert 唯一。
